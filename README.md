# DevMachine — плагины для агентов разработки

Маркетплейс плагинов Claude Code. Сейчас в нём один плагин — **tracker**: агент сам заводит, ведёт, передаёт и
закрывает задачи в трекере команды DevMachine.

```
/plugin marketplace add devmachine-ai/agent-plugins
/plugin install tracker@devmachine
/tracker-setup
```

Нужен Node.js 18+. Подробности — [`tracker/README.md`](tracker/README.md).

Репозиторий — зеркало: изменения вносятся в основном репозитории DevMachine и выкладываются сюда скриптом.
